# PRECEPTA full-pilot derivation decisions — v0.3.0-pilot

## Scope

The website now evaluates all **32 canonical PRECEPTA patterns** across all five domains.

The canonical catalogue and signatures come from the Practitioner Manual. The core/supporting/modifier decomposition is a provisional model specification for empirical testing, not a claim that those weights were empirically established.

## RC decision applied consistently

`RC` means **Re-Entry Cost**.

The older construct **Regulation Capacity** is retired. Where old PRECEPTA signatures used `RC` in that older sense, v0.3 revises the mechanism explicitly rather than silently reinterpreting it.

Affected rules revised in v0.3:

- Low-Feedback Autonomy
- Impulsive / Enthusiastic Communicator
- Masked High-Cost Performer
- Affective Floodgate
- Affective Decoupler

## Deliberately non-direct patterns

The following are not automatically inferred from the 26 static scores because their defining phenomenon is not directly measured:

- Fast Insight / Slow Explanation
- Deadline-Unlocked Starter
- Impulsive / Enthusiastic Communicator
- Stim-Regulation Loop
- Time-Blind Sprinter

They remain available in structured missing-pattern feedback, with targeted follow-ups.

## Context-sensitive candidates

Several patterns can be suggested by the 26-dimensional architecture but still require a context or dynamic caveat, including:

- Domain-Locked Expert
- Meaning-Gated Performer
- Start–Stop Oscillator
- Masked High-Cost Performer
- Ethical Precision Speaker
- Affective Floodgate
- Ethical Amplifier
- Sensory-Seeking Stabilizer

## Display policy

The result page presents:

1. all strong compatible patterns;
2. then the strongest remaining candidate in any PRECEPTA domain not yet represented;
3. maximum 12 presented patterns.

This is a presentation rule, not a claim that unshown candidates are false.
